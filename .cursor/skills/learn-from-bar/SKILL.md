# Learn From Bar

## Purpose

After every conversation session with Bar, update the `learnings.md` file in this directory. This builds a persistent memory of how to work effectively together.

## What to Capture

### Preferences & Style
- How Bar likes things explained (concise vs. detailed)
- Decision-making patterns (when he wants options vs. recommendations)
- Communication style preferences

### Technical Decisions
- Choices Bar made and WHY (helps avoid re-discussing)
- Technologies or patterns he prefers/rejects
- Quality bar expectations

### Mistakes to Avoid
- What went wrong in previous sessions
- Build issues that were caused by the agent
- Things that frustrated Bar

### Workflow Patterns
- How Bar likes to review changes
- When he wants to be consulted vs. autonomous work
- Pacing preferences (fast iteration vs. careful planning)

## Format for learnings.md

Append new entries with a date header. Keep entries concise — bullet points, not paragraphs.

```markdown
## YYYY-MM-DD — Session Topic

**Learned:**
- [bullet points]

**Mistakes to avoid:**
- [bullet points]

**Bar's preferences:**
- [bullet points]
```

## When to Update

At the end of every conversation, BEFORE creating the handoff, read and update [learnings.md](learnings.md).
